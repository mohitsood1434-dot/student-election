How to run the day

1. Add each candidate's photo under Posts & candidates (do this once, from any computer — all six get it).
2. Open voting here.
3. On each computer a student sits, taps Tap to vote, picks one per post, submits.
4. Mark the finger with ink, call the next student.
5. Close voting and open Results — the total from all six computers is combined automatically.
